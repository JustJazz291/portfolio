#  Threaded Portfolio — Janhavi Shete

A storytelling-based developer portfolio built around a **knitting and thread metaphor**, where a single continuous thread visually connects my journey across skills, projects, and experience.

> “Every thread tells a story. Here’s mine.”

 Live Website

🔗 https://justjazz291.github.io/portfolio/

---

📌 About the Project

This portfolio is designed as an interactive experience, not just a static website.

* A **3D yarn ball** introduces the journey
* A **single animated thread** connects all sections
* Content unfolds progressively as the user scrolls
* The journey ends with a **thread forming a heart/knot**

The goal was to combine **creativity + engineering** into a memorable UI/UX.

---

## 🛠 Tech Stack

* **Frontend:** React (Vite)
* **3D Graphics:** Three.js (React Three Fiber)
* **Animations:** Framer Motion
* **Styling:** Tailwind CSS / CSS
* **Deployment:** GitHub Pages
* **Version Control:** Git & GitHub

---

## ✨ Features

* 🎨 Minimal, clean UI with notebook-style grid background
* 🧶 3D yarn ball with subtle motion
* 🧵 Single continuous SVG thread across the website
* 🎬 Scroll-based animations and transitions
* 💡 Text animations (word-by-word reveal, underline effects)
* 📱 Fully responsive design
